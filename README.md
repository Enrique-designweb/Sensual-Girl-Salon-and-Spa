# Sensual-Girl-Salon-and-Spa
Plataforma web premium y sistema de gestión (POS/CRM) para Sensual Girl Salon &amp; Spa en Santa Clara. Especializados en masajes terapéuticos, drenaje linfático, estética facial avanzada (microneedling, exosomas) y armonización. Desarrollado con Next.js 16, Tailwind v4, PWA y arquitectura Local-First.
