Sensual Girl | Salón & Spa
Belleza, bienestar y tecnología premium.

Bienvenido al repositorio oficial de la plataforma web y sistema de gestión de Sensual Girl, el salón y spa de referencia en Santa Clara, Cuba.

Nuestra misión es fusionar la estética avanzada con el bienestar profundo, ofreciendo un refugio de lujo y confianza. Este sistema fue diseñado para digitalizar toda la operación del salón, garantizando una experiencia de usuario inigualable y un control administrativo absoluto.

✨ Nuestras Especialidades:

Masajes y Terapias (Legna): Masajes relajantes y descontracturantes, drenaje linfático, reflexología podal, masajes terapéuticos y tratamientos post-operatorios.

Estética Facial (Kleyan): Limpiezas faciales profundas y con dermaplaning, microneedling (péptidos, ácido hialurónico, PDRN), plasma rico en plaquetas, exosomas, toxina botulínica y armonización facial.

🚀 Características del Sistema:

E-commerce & Reservas: Flujo de reservas inteligente con validación de horarios en tiempo real y notificaciones por WhatsApp.

PWA (Progressive Web App): Instalable en dispositivos móviles y con soporte offline para zonas de baja conectividad.

Panel de Administración: Gestión de citas, control de ingresos y roles de usuario (Legna y Kleyan tienen paneles independientes).

Autenticación: Login manual seguro y acceso con Google OAuth para las especialistas.

Tech Stack: Next.js 16 (App Router), React 19, Tailwind CSS v4, PostgreSQL (Neon), NextAuth v5, Framer Motion.
